
| Feature     | TCP                 | UDP                  |
| ----------- | ------------------- | -------------------- |
| Connection  | Connection-oriented | Connectionless       |
| Reliability | Reliable            | Unreliable           |
| Ordering    | Guaranteed          | Not guaranteed       |
| Speed       | Slower              | Faster               |
| Examples    | HTTP, SSH, FTP      | DNS, VoIP, Streaming |
