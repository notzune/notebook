C is a general purpose programming language created in the 1970s. it is used in the creation of operating systems, especially in [[Kernel|kernels]].

C is an [[Imperative programming|imperative]] [[Procedural programming|procedural]] language that supports [[Structured programming|structured programming]], [[Scope (computer programming)|lexical variable scope]], and [[Recursion|recursion]], with a [[Type system|static type system]]. 

It was designed to be compiled to provide [[Low-level programming|low-level]] access to [[Computer memory|memory]] and constructs that map efficiently to [[Machine code|machine instructions]].
