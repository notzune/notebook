in [[Computer networking|computer networking]], the User Datagram Protocol (UDP) is one of the core [[Communication protocol|communication protocols]] of the [[Internet protocol suite|internet protocol suite]] used to send messages ([[Datagram|datagrams]] in [[Network packet|packets]]) to other hosts on an [[Internet protocol (IP)|IP]] network.

within an IP network, UDP does not  require prior communication to set up [[Communication channels|communication channels]] or data paths.

UDP is a [[Connectionless communication|connectionless]] protocol, meaning that messages are sent without negotiating a connection and that UDP does not keep track of what it has sent. 

UDP provides [[Checksum|checksums]] for [[Data integrity|data integrity]], and [[Port (computer networking)|port numbers]] for addressing different functions at the source and destination of the datagram.
